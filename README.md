# To-Do-Tracker
# ⚡ Trackify – Productivity & Expense Management Suite

A modern, responsive productivity web application that combines 
task management, personal expense tracking, and analytics 
in one unified dashboard.

Trackify helps users organize daily tasks, monitor their 
finances, track productivity, and make better decisions 
through real-time statistics and insights.

---

## 🚀 Project Overview

Trackify is a browser-based productivity application designed 
to simplify daily task management and personal financial tracking.

Instead of using separate applications for managing tasks 
and expenses, Trackify brings everything together in one place.

It provides an interactive dashboard with task statistics, 
expense summaries, filtering, searching, and data visualization.

---

## ✨ Key Features

### 📋 1. Task Management

- Create and manage daily tasks.
- Edit and delete existing tasks.
- Mark tasks as completed.
- Set task priorities (High, Medium, Low).
- Assign categories to tasks.
- Set task due dates.
- Add additional notes.
- Search tasks instantly.
- Filter tasks by status and priority.
- Sort tasks by date, priority, and title.

### 💰 2. Expense Management

- Track personal income and expenses.
- Add new financial transactions.
- Categorize financial records.
- Select payment methods.
- Track transaction dates.
- Search and filter transactions.
- Sort transactions by date and amount.
- Calculate income, expenses, and net balance.
- Support multiple currencies.

### 📊 3. Analytics Dashboard

- Overall productivity score.
- Task completion statistics.
- Net financial balance.
- High-priority pending tasks.
- Spending breakdown by category.
- Task priority distribution.

### 💾 4. Data Management

- Automatic data persistence using Browser LocalStorage.
- Export application data as JSON.
- Import previous JSON backups.
- Reload sample demonstration records.

### 🎨 5. User Interface

- Modern dashboard design.
- Dark and Light theme support.
- Responsive layout.
- Interactive navigation.
- Search functionality.
- Toast notifications.
- Keyboard shortcuts.
